Acesso administrativo

Conecte este painel ao repositório do site para editar o catálogo e as imagens. O token é mantido somente na memória desta aba e não é salvo no site nem no navegador.

Crie um token fine-grained limitado ao repositório ma-vie-site, com permissão Contents: Read and write. Não compartilhe o token.

Este painel usa a API oficial do GitHub. Ao sair ou fechar a aba, o token deixa de estar disponível nesta página. Se o token expirar, gere outro nas configurações do GitHub.

Gerenciar sua loja

Edite os produtos disponíveis, monte novas cestas e escolha quais itens o cliente poderá personalizar.

As alterações só aparecem na loja depois de salvas e publicadas pelo GitHub Pages.
